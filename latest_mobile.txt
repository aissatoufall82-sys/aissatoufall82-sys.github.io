- 大部分JavaScript程序员默认了他们的骑行或Die框架
  原出处: The Register · 财经媒体
  信源分类: The Register · 专业媒体/市场背景 · 11-03 22:51 北京时间
  原题: Pokémon bakeoff reveals best JavaScript frameworks for AI
  原文中文译读: Pokémon bakeoff 揭示了AI的最佳JavaScript框架. 大部分JavaScript程序员默认了他们的骑行或Die框架，但这样的忠诚性在他们指派AI代理进行肮脏的工作时会阻碍他们. 人性友好的工具并不一定是模型驱动的微型工具最有效的工具. "我的网络开发界的宠物小狗之一，就是我们所做的决定如此之多，基于气息的，"写道，西雅图的诺兰·劳森(Noran Lawson)目前是AI安全公司Socket的开发者. 简言之，JavaScript战争已经持续了十几年，每个新框架都有望治愈去年发行的灾难。 劳森不希望这些情绪偏见渗入AI领域，他创造了一个基准来比较不同JavaScript框架在同一个代理模式下的表现。他随后对12个JavaScript框架进行了测试，并在一个职位上公布了在构建成本、可维持性和其代理软件的最终用户性能方面比较每个框架的结果。 一般来说，代理商往往比起客户端重的“单一Page App”框架(Single-Page App(SPA)框架)更高效地与服务器框架合作。但最大的外卖应该较少争议:代理商最好地利用那些有利于公约、API稳定性和精密度的框架。 如何比较JavaScript框架为实验，劳森为克劳德代码代理商写了一套指令，用PokéAPI构建一个基本的Pokémon网络应用程序。 该模型在12个不同的框架和JavaScript堆栈上使用了相同的设置:Angular, Astro, Gracile with Lit, Hono with htmx, vanilla JavaScript with Vite, Next.js, Nuxt, Quik, React Router, TanStack Start, SolidStart, 和SvelteKit. Lawson通过5个独立的沙盒运行来评价每个堆栈;重复的迭代平了模型性能的差异. 为了验证所生成的应用程序满足了规格，劳森安装了一个自定义的自动测试套件，该套件询问浏览器的无障碍树，以确保按钮和输入等交互元素不是假的—— LLMs偶尔也会使用快捷键。 劳森还用Google灯塔来测量传输大小和运行时间性能。如果框架指定了官方的MCP服务器、Claude 插件和代理服务器技能文件，劳森将它们作为代理商的资源(尽管他们并不总是被咨询 )。否则，他不会授权任何特定架构来发布应用程序。 比较 12 JavaScript 框架，成本- 效益最高的建筑和成本最高的建筑之间的差别是巨大的，至少可以说，与最拍拍手者的努力是最大的。如果您想以成本效益高的方式构建一个 Pokéworld,那么最强的赌注是Hono 和 htmx 搭配。这个技术标记小组运行最经济，每Pokéapp 的中位成本为2.67美元。也许这并不奇怪，因为 duo 运行在服务器上，从而消除了一系列所需的检查，将客户端和服务器之间的建筑分割同步起来。这也有助于将代码最小化，从而减少消耗输出符号。 Astro (2.76) 几乎同样有效。 Astro 和 Hono/ htmx 一样，Astro 做所有服务器边。 服务器边的数据压缩也有助于Astro 最快的中位时间在 8.2 分钟内构建和测试应用程序。 Nuxt (2.82)是类似 SPA 的方法最有成本效益的选项。 Nuxt 会在服务器上生成代码，可以在客户端上加水。 Nuxt 实际上是在 Vue.js 上构建的，但“ opinioned ”, 取消了许多代理商必须撰写的锅炉板。 Nuxt 也处理内部的数据传输和文件路由，这在代码上更不会被夸大。 值得指出的是，Nuxt消耗了数量最少的标志(385万),尽管这并不使它成为最便宜的标志，因为Claude对输入和输出的标志收取了不同的收费。 Nuxt用1 415行代码生产了该应用，这仅次于Hono/htmx的1 370行。 总体而言，这三大框架在相互错误的幅度内，这意味着其中任何一个都有可能根据LLM的一天得到最高分数。然而，有些更传统的框架却落后了。 SvelteKit型的应用软件需要4.28美元才能生成，而代理商要反复返回SvelteKit文档，才能更好地掌握最近更新的Svelte的操作情况。 Angular是代理商制造应用软件的最昂贵方式，耗资4.97美元，而耗时17.2分钟，并咀嚼了976万个信使(代理商在五次尝试中两次甚至未能完成一个工作应用 )。结果所有的应用都加速了灯塔的无障碍性和性能测试。 Lawson承认这是一个相当简单的应用软件。 Astro的应用的装载时间最快(称为最大内容绘画或LCP ) 8。

Binance表示黑客使用假工作面试，恶意软件和损坏内部AI工具渗透钱包基础设施，导致创纪录的10月29日网络攻击导致超过60亿美元的资产从世界上最大的密码交换中被盗. 攻击者"花费了几个月的时间在他们中间建路",Binance联合CEORichard Teng星期二告诉CNBC的"Squawk on the Street",拒绝通过一名员工的笔记本电脑出现单一故障点的建议. "6月，[攻击者]建立了一个假版的开发者工具，并引诱我们的一位工程师安装了这个工具",他补充说，"9月，他们作为招募者，与另一位工程师进行了一系列的工作面试，结果在编码中包含着隐蔽的恶意软件，旨在逃避安全.他们从那里通过我们内部的AI工具暴力移动，并获得进入这个系统的机会，这违反了授权我们的钱包交易的系统",他还说，宾南斯补充了63.4亿美元受影响的资产的98%,并且它仍在购买未清，更不稳定的资产. 滕本人并没有将袭击归咎于朝鲜，而是承认联邦调查局已经将其与与TraderTraitor集团捆绑的朝鲜黑客联系起来. 袭击的准备工作始于6月，一位Binance Wallet DevOps工程师下载了一个被篡改的Homebrew安装"在搜索引擎上搜索后安装一个流行的AI编码工具",根据Binance星期二发布的安全报告. 该公司表示，它发现了可疑的活动，更换了工程师的装置并更换了证书，作为防范措施，但当时该雇员的"我们钱包基础设施团队中的角色及其相关同事暴露于黑客手中",随着宾纳斯努力从事件中恢复，它暂时限制了某些提款，承诺弥补所有客户损失，并挖掘自己的储备来补充受影响的资产. 宾纳斯和包括泰瑟，圆圈和里普尔在内的行业伙伴据报道已经冻结了约30亿美元的资产，尽管一些被盗资金继续通过清洗渠道转移. Coinbase阻止了对受损钱包的转移，并提供了宾纳斯的直接援助. 尽管这一事件代表了重大的安全漏洞，但比南斯坚持认为，它仍然在财政上是可靠的，并专注于识别脆弱性、追回剩余资金和防止另一起袭击。这次黑客袭击引发了一场急速但短暂的冲击，导致整个地下市场的信心受到冲击，尤其是与以往主要交易所的失败相比。 投资者们现在正在观察比南斯能否完全恢复对集中交易的信心。 截止周二宾南斯重建了受影响的钱包系统和内部AI工具，更换了受损的装置，退役的证书和与受影响的工程师相关的信物，并扩大了对员工设备的安全扫描，滕格告诉了"Squawk on the Street","我们也正在让一位独立专家来审查我们所做的一切，随着调查的继续，我们将不断加强我们的防御",滕格说"我们正与执法机构和行业伙伴们全天候合作，追踪和冻结被窃资金用于这一战线".
