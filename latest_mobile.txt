  原文中文译读: 新加坡的制造商尽管存在地缘政治云雾，却仍然对AI的需求保持乐观。除了生物医学制造和运输工程项目之外，所有集群都拥有更大的劳动力。新加坡制造商期望在未来六个月内，在全球AI需求驱动下，尽管地缘政治和经济不确定性。 EDB调查发现，24% 的净加权率预期条件会更好，比12%,而72%则预计就业将大致相似。 精密工程和电子技术最乐观，但化学品是最弱的集群。 企业引证了高成本、海外竞争、关税和原油供应的担忧。 SINGAPORE—— 制造商对未来六个月仍持乐观态度，这与人工智能相关联的强劲全球需求使这一前景更加乐观，尽管地缘政治发展给经济前景蒙上阴影。 与第三季度相比，2026年10月至2027年3月，新加坡经济发展委员会(EDB)11月2日公布的一项调查显示，净加权平衡为24%,这与前一次调查的12%净加权平衡相比有所上升。 加权平衡为29%的公司预计条件会改善，5%的公司预计商业状况会变弱。在就业方面，加权加权72%的制造商预计第四季度的就业水平与第三季度大致相同。除了生物医学制造和运输工程项目之外，所有集群的劳动力都更大。 总体而言，就业净加权平衡为14%。 从集群来看，精密工程是最乐观的(+48% ), 由半导体相关设备制造者支持，他们期望全球AI相关投资持续扩大。 电子集群(+42% ) 也期望着一种强劲的前景，由AI应用中使用的半导体的强劲订单驱动。 生物医学制造(+14%)和一般制造(+7% ) 也是积极的。 运输工程企业(+1% ) 期望条件大致相似，并举出材料、燃料和货运以及海外竞争成本上升为主要头风。 化学集群是最悲观的(-13% )。 石油部分企业(-28% ) 仍然对原油原料供应的持续不确定性感到关切。 第四季度，有34%的厂商预计产出会比上季度增加。电子(+55%)和精密工程(+54%)是领先的。在电子领域，半导体和计算机外围及数据存储部分预计生产量会增加，以适应AI数据中心的强劲需求。精密工程公司预计半导体相关设备、连接线和金属精密组件的产量会增加。生物医学制造(+19%)公司预计生产更活跃的药物成分和生命科学仪器。一般制造(+10%)也是积极的，除印刷项目外，每个部分都预测产出较高。食品、饮料和烟草部分预计对牛奶和饮料产品的出口需求会增加。 运输工程的产出预期(0%)参差不齐，航空航天和陆地部门预计活动会增加，而海洋和近海工程部门则认为油气田设备产量较低，因为地缘政治不确定因素影响着订单;化学品(+5%)是最弱的集群;出口订单方面，23%的加权公司预计第四季度订单会面临挑战;前两个因素是海外对手的价格竞争，以及国外的政治或经济条件，包括地缘政治发展、关税和通货膨胀压力。
