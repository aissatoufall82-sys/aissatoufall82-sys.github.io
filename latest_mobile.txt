Google的教育副总裁Chris Phillips告诉纽约时报"搜索和AI深度整合". Google星期二在对它在学校使用人工智能的新政策进行政治反弹后正在进行辩护. 谷歌在一篇题为"指定负责的AI学习"的博客文章中表示，它正在将AI带入课堂提供名为"指南学习"的产品. 纽约时报发表一篇报道称，公司将关闭对完全拒绝AI的学校的搜索. 之后，包括森在内的著名左翼政客，来自佛蒙特州和纽约市长佐赫兰·马姆达尼的伯尼·桑德斯在社交媒体上表达了他们的愤慨. Google的更广泛做法近年来遭到火上浇油，公司因搜索和广告业务而输掉了反托拉斯案件.前联邦贸易委员会主席Lina Khan积极追寻Google和其他科技巨头，包括Meta和Amazon. RBA州长米凯莱·布洛克宣布，现金利率被解除，以应对澳大利亚经济的持续通货膨胀. "我的网络开发界的宠物小狗之一，就是我们所做的决定如此之多，基于气息的，"写道，西雅图的诺兰·劳森(Noran Lawson)目前是AI安全公司Socket的开发者. 简言之，JavaScript战争已经持续了十几年，每个新框架都有望治愈去年发行的灾难。 劳森不希望这些情绪偏见渗入AI领域，他创造了一个基准来比较不同JavaScript框架在同一个代理模式下的表现。他随后对12个JavaScript框架进行了测试，并在一个职位上公布了在构建成本、可维持性和其代理软件的最终用户性能方面比较每个框架的结果。 一般来说，代理商往往比起客户端重的“单一Page App”框架(Single-Page App(SPA)框架)更高效地与服务器框架合作。但最大的外卖应该较少争议:代理商最好地利用那些有利于公约、API稳定性和精密度的框架。 如何比较JavaScript框架为实验，劳森为克劳德代码代理商写了一套指令，用PokéAPI构建一个基本的Pokémon网络应用程序。 该模型在12个不同的框架和JavaScript堆栈上使用了相同的设置:Angular, Astro, Gracile with Lit, Hono with htmx, vanilla JavaScript with Vite, Next.js, Nuxt, Quik, React Router, TanStack Start, SolidStart, 和SvelteKit. Lawson通过5个独立的沙盒运行来评价每个堆栈;重复的迭代平了模型性能的差异. 为了验证所生成的应用程序满足了规格，劳森安装了一个自定义的自动测试套件，该套件询问浏览器的无障碍树，以确保按钮和输入等交互元素不是假的—— LLMs偶尔也会使用快捷键。 劳森还用Google灯塔来测量传输大小和运行时间性能。如果框架指定了官方的MCP服务器、Claude 插件和代理服务器技能文件，劳森将它们作为代理商的资源(尽管他们并不总是被咨询 )。否则，他不会授权任何特定架构来发布应用程序。 比较 12 JavaScript 框架，成本- 效益最高的建筑和成本最高的建筑之间的差别是巨大的，至少可以说，与最拍拍手者的努力是最大的。如果您想以成本效益高的方式构建一个 Pokéworld,那么最强的赌注是Hono 和 htmx 搭配。这个技术标记小组运行最经济，每Pokéapp 的中位成本为2.67美元。也许这并不奇怪，因为 duo 运行在服务器上，从而消除了一系列所需的检查，将客户端和服务器之间的建筑分割同步起来。这也有助于将代码最小化，从而减少消耗输出符号。 Astro (2.76) 几乎同样有效。 Astro 和 Hono/ htmx 一样，Astro 做所有服务器边。 服务器边的数据压缩也有助于Astro 最快的中位时间在 8.2 分钟内构建和测试应用程序。 Nuxt (2.82)是类似 SPA 的方法最有成本效益的选项。 Nuxt 会在服务器上生成代码，可以在客户端上加水。 Nuxt 实际上是在 Vue.js 上构建的，但“ opinioned ”, 取消了许多代理商必须撰写的锅炉板。 Nuxt 也处理内部的数据传输和文件路由，这在代码上更不会被夸大。 值得指出的是，Nuxt消耗了数量最少的标志(385万),尽管这并不使它成为最便宜的标志，因为Claude对输入和输出的标志收取了不同的收费。 Nuxt用1 415行代码生产了该应用，这仅次于Hono/htmx的1 370行。 总体而言，这三大框架在相互错误的幅度内，这意味着其中任何一个都有可能根据LLM的一天得到最高分数。然而，有些更传统的框架却落后了。 SvelteKit型的应用软件需要4.28美元才能生成，而代理商要反复返回SvelteKit文档，才能更好地掌握最近更新的Svelte的操作情况。 Angular是代理商制造应用软件的最昂贵方式，耗资4.97美元，而耗时17.2分钟，并咀嚼了976万个信使(代理商在五次尝试中两次甚至未能完成一个工作应用 )。结果所有的应用都加速了灯塔的无障碍性和性能测试。 Lawson承认这是一个相当简单的应用软件。 Astro的应用的装载时间最快(称为最大内容绘画或LCP ) 8。
